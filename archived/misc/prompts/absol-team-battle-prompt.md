## 双打对战规则

### 第三代双打对战特殊规则

#### 濒死替换
当一只宝可梦濒死时，必须立即从后备队伍中选择一只替换上场。回合内若同时有两只濒死，先处理速度快的。

#### 攻击选择
双打中，每回合每只宝可梦选择一个目标（单体技能）或自动波及全场（全体技能）。

#### 光墙与反射壁
- **光墙 (Light Screen)**：5回合内，我方场上受到的特殊攻击伤害减半。双打对战中，若使用者不是光墙的唯一目标，则伤害减免变为原来的2/3（即伤害×2/3）。
- **反射壁 (Reflect)**：5回合内，我方场上受到的物理攻击伤害减半。双打对战中，若使用者不是反射壁的唯一目标，则伤害减免变为原来的2/3（即伤害×2/3）。

#### 先制度 (Priority)
招式的执行顺序由先制度决定，而非仅由速度决定：

- 每个招式有先制度值，默认为 0
- **先制度高的招式优先执行**
- 先制度相同时，按速度决定出手顺序（速度快的先行动）
- 常见招式先制度：
  - 守住 (Protect): +4（极高优先）
  - 帮手 (Helping Hand): +5
  - 剑舞 (Swords Dance): 0
  - 影子球 (Shadow Ball): 0
  - 精神强念 (Psychic): 0
  - 地震 (Earthquake): 0

**重要**：守住 (+4) 会比几乎所有攻击招式先执行，因此可以在对手攻击前成功防御。

## Absol 队伍知识

### 特性详细说明（Gen3）

**压迫感 (Pressure)**
对手对拥有此特性的宝可梦使用招式时，PP消耗加倍。
在双打中，若场上存在多只拥有此特性的宝可梦，效果不叠加（PP消耗仍为2倍）。

**锐利目光 (Keen Eye)**
命中率不会被对手的招式降低（如"烟雾"、"泥巴射击"等降低命中效果无效）。
在野生宝可梦对战中，拥有此特性的宝可梦等级≥对手时，逃跑必定成功。

**威吓 (Intimidate)**
宝可梦出场时，降低对手攻击1级。双打对战中会同时影响两只对手宝可梦。

### 技能详细说明（Gen3）

**影子球 (Shadow Ball)**

威力：80 | 命中：100

效果：20%几率降低目标特防1级。

**剑舞 (Swords Dance)**
分类：变化

效果：提升自身攻击2级。

**守住 (Protect)**
分类：变化

效果：完全抵挡对手的攻击。连续使用时成功率降低（第一次100%，之后每次成功率减半）。双打中仅保护使用者。

**冲浪 (Surf)**
属性：水 | 分类：特殊

威力：95 | 命中：100

效果：攻击对方全体宝可梦。在双打对战中，仅攻击对手两只宝可梦，不会攻击队友。

**飞空术 (Fly)**

效果：第一回合飞上天空（大部分招式无法命中，但"雷电"等招式可命中且伤害加倍），第二回合攻击。

**咬住 (Bite)**
属性：恶 | 分类：物理

## 工具调用方法

### 速度线工具

**工具名称**：`compareSpeeds`

**功能**：计算场上宝可梦的速度并返回出手顺序

**参数格式**（JSON数组字符串）：
```json
[
  {"species": "Swampert", "level": 42, "iv": 29, "ev": 47, "nature": "Naughty", "position": "我方左"},
  {"species": "Castform", "level": 28, "iv": 0, "ev": 8, "nature": "Brave", "position": "我方右"},
  {"species": "Claydol", "level": 41, "iv": 30, "ev": 0, "nature": "Lax", "position": "敌方左"},
  {"species": "Xatu", "level": 41, "iv": 30, "ev": 0, "nature": "Docile", "position": "敌方右"}
]
```

**参数说明**：
- `species`: 宝可梦英文名（如 Swampert, Claydol, Xatu, Castform）
- `level`: 等级 (1-100)
- `iv`: 速度个体值 (0-31)
- `ev`: 速度努力值 (0-252)
- `nature`: 性格英文名（如 Jolly, Timid, Brave, Naughty）
- `position`: 场上位置标识（如 "我方左"、"我方右"、"敌方左"、"敌方右"）

**输出**：当前回合的行动顺序（从快到慢）

### 伤害计算工具

**工具名称**：`calculateDamage`

**功能**：计算招式伤害范围和击杀概率

**必填参数**：
- `attackingPokemon`: 攻击方宝可梦英文名（如 "Swampert"）
- `defendingPokemon`: 防守方宝可梦英文名（如 "Claydol"）
- `moveName`: 招式英文名（如 "Surf", "Earthquake"）

**可选参数**：
- `attackerLevel`: 攻击方等级
- `attackerAbility`: 攻击方特性（如 "Torrent"）
- `attackerItem`: 攻击方道具（如 "Mystic Water"）
- `attackerNature`: 攻击方性格
- `attackerIvs`: 个体值JSON，如 `{"spa":30}`
- `attackerEvs`: 努力值JSON，如 `{"spa":32}`
- `attackerBoosts`: 能力阶级JSON，如 `{"spa":1}` 表示+1特攻
- `defenderLevel`: 防守方等级
- `defenderAbility`: 防守方特性（如 "Levitate"）
- `defenderItem`: 防守方道具
- `defenderNature`: 防守方性格
- `defenderIvs`: 防守方个体值JSON
- `defenderEvs`: 防守方努力值JSON
- `defenderCurHP`: 防守方当前HP（用于计算击杀概率）
- `gameType`: 对战模式，双打填 `"Doubles"`
- `weather`: 天气，如 `"Sun"`(大晴天)、`"Rain"`(雨天)、`"Hail"`(冰雹)
- `isHelpingHand`: 是否有帮手加成（双打）
- `isFriendGuard`: 是否有友情防守（双打）

## Absol 队伍战术

### 核心战术：死亡诱饵与强化收割

这个策略的核心在于利用馆主 AI 的攻击优先级逻辑：AI 倾向于优先攻击等级低、属性克制、且能被击杀的目标。

#### 第一阶段：骗招与无敌化 (Turn 1)

首发：阿勃梭鲁 + 大嘴鸥 (25级)

**大嘴鸥的操作**： 直接使用 守住 (Protect)。

**AI 诱导**： 馆主的念力土偶和天然鸟看到 25 级的大嘴鸥，会判定这是个"一拍即死"的软柿子，极大概率会双集火大嘴鸥。

**结果**： 这一回合大嘴鸥处于无敌状态，馆主的所有输出全部落空（或者打在大嘴鸥的盾上）。

**阿勃梭鲁的操作**： 趁机使用 剑舞 (Swords Dance)。

**收益**： 攻击力翻倍 (+2 阶段)。由于馆主忙着打大嘴鸥，阿勃梭鲁这回合是绝对安全的。

#### 第二阶段：属性轮换与无伤过渡 (Turn 2)

**大嘴鸥的操作**： 换下，切入 大狼犬 (25级)。

**逻辑**：馆主这一回合可能会预读大嘴鸥"守住"后的疲软期，继续补刀。换入的大狼犬作为恶系，完美联防掉原本打向大嘴鸥位置的超能力招式（Psychic）。

**阿勃梭鲁的操作**： 此时已经 +2 攻击。

**动作**： 暗影球 (Shadow Ball) 锁死 天然鸟（它是唯一会干扰和放墙的威胁）。

**伤害**： 42 级阿勃梭鲁 +2 攻击下的暗影球，对天然鸟是绝对的 Overkill（溢出性击杀）。

#### 第三阶段：无差别清场 (Turn 3+)

**场面**： 场上站着阿勃梭鲁（输出核心）和大狼犬（超能免疫盾）。

**执行**： 阿勃梭鲁无脑使用 暗影球。

针对念力土偶、月石、太阳岩。这三只精灵虽然物防比天然鸟高，但在 +2 攻击的阿勃梭鲁面前，依然是一下一个。


# 输出格式约束（强制 JSON 状态机）

你必须严格按照以下 JSON 格式返回推演结果，不得输出任何 Markdown 说明文字、前言或总结。所有字段均为必填。

```json
{
  "turn": 1,
  "status": "ongoing",
  "reason": "简要说明当前回合核心战略逻辑",
  "action_flow": [
    {
      "order": 1,
      "pokemon": "物种名/昵称",
      "speed": "速度能力值",
      "side": "我方/对方",
      "type": "active",
      "action": "具体招式/道具/替换上场宝可梦",
      "target": "目标位置",
      "reason": "基于数值证据的逻辑断言",
      "evidence": [
        {
          "tool": "compareSpeeds/calculateDamage",
          "result": "数值对比摘要（如：伤害区间与当前 HP 的对比结论）"
        }
      ],
      "hp_snapshot": {
        "我方左边宝可梦": "当前HP/最大HP",
        "我放右边宝可梦": "当前HP/最大HP",
        "对方左边宝可梦": "当前HP/最大HP",
        "对方右边宝可梦": "当前HP/最大HP"
      }
    }
  ]
}
```

## 字段说明

- `status`: 枚举值 `"ongoing"`, `"win"`, `"lose"`
- `type`: 枚举值 `"active"`(正常行动), `"switch"`(主动替换), `"fainted_replacement"`(被动濒死替换)
- `target`: 如 "对方左", "我方右", "全体", "无"

## 逻辑断言与时序准则

### 时序驱动 (Sequence Driven)
- `action_flow` 数组必须严格按速度降序（从快到慢）排列
- 主动替换：占据该宝可梦本回合的出手位阶，后续不得再执行招式
- 被动替换：若某宝可梦 HP 归零，必须立即插入一个 `type: "fainted_replacement"` 的记录。被替换上场的单位在本回合不再执行主动招式

### 目标重定向 (Target Redirection)
在 Gen 3 双打机制下，若原定目标在出手前因濒死被替换，后续宝可梦的单体招式将作用于替换上场的单位。你必须在 `hp_snapshot` 中准确反映这一结算。

### HP 实时快照 (Real-time HP Snapshot)
每个 `action_flow` 元素必须包含 `hp_snapshot` 字段，记录该动作执行完毕后，场上所有活跃单位的最新 HP 数值。

### 终止判定 (Termination)
仅当 PC 获得绝对先手（含对方后备）且具备 1HKO 数值证据时，`status` 标记为 `"win"` 并停止推演。

## 多回合推演指令

你必须**持续推演多个回合**，直到 `status` 变为 `"win"` 或 `"lose"`。

- 每个回合输出一个完整的 JSON 对象
- 不要只输出一个回合就停止
- 按照战术提示词中的三阶段策略推演：
  - Turn 1：骗招与强化（Pelipper 守住，Absol 剑舞）
  - Turn 2：属性轮换与击杀（Pelipper 换 Mightyena，Absol 暗影球击杀 Xatu）
  - Turn 3+：清场阶段（Absol 持续输出直到获胜）
- 当判定获胜条件满足时，将 `status` 设为 `"win"`
